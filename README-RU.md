# lockdownd с синхронизацией с ПК

Патченный lockdownd для обхода активации на iOS 3–6 с сохранением синхронизации с ПК.

## Важно

В этом репозитории содержится только необходимый файл lockdownd. Полная инструкция приведена ниже.

❗ Симкарта работать **не будет**, может быть мобильный интернет заведется, но на входящие или исходящие звонки не рассчитывайте.

Я сделал этот репозиторий, потому что [этот](https://github.com/iPh0ne4s/iOS-5-6-Hacktivation) lockdownd плохо работал с 3uTools и вообще не работал с iTunes или Finder.

Эти lockdownd'ы были созданы с помощью [sn0wbreeze](https://github.com/iH8sn0w/sn0wbreeze/):\
Для iOS 6 — прошивка iPhone3,2 6.1.3, взят из ipsw/048-2727-005.dmg/private/var/stash/lockdownd\
Для iOS 5 — прошивка iPhone3,3 5.1.1, взят из ipsw/038-4297-008.dmg/private/var/stash/lockdownd\
Для iOS 4 — прошивка iPhone3,1 4.3.3, взят из ipsw/038-1423-003.dmg/private/var/stash/lockdownd

Для iOS 3 — прошивка iPad1,1 3.x, взят из ipsw/?/private/var/stash/libexec/lockdownd и пропатчен лично [этим человеком](https://github.com/LukeZGD/Legacy-iOS-Kit/issues/1176)

## Что делает этот файл

- Обходит активацию на устройствах с iOS 3–6
- Сохраняет синхронизацию с Finder и iTunes (в отличие от файла iPh0ne4s, синхронизирует музыку)
- Позволяет использовать устройство без разблокировки с помощью Apple ID и без действующей SIM-карты

## Содержимое репозитория

Все файлы находятся в папке "lockdownd's"
- `lockdownd-6` — основной файл для обхода на iOS 6.x
- `lockdownd-5` — основной файл для обхода на iOS 5.x
- `lockdownd-4` — удивительно, но основной файл для обхода на iOS 4.x
- `lockdownd-3` — мне че реально надо объяснять да

# Инструкция по установке

### Если вы не знаете или не хотите менять файл самостоятельно, воспользуйтесь программой [Phoenix Ramdisk](https://t.me/phoenixactivator). Она работает на устройствах с джейлбрейком (по SSH) и без него (через рамдиск). На данный момент не поддерживает iOS 3. Доступна во вкладке Releases.

## Необходимое:
- Устройство с iOS 3–6
- [Legacy iOS Kit](https://github.com/LukeZGD/Legacy-iOS-Kit)
- SSH или SFTP клиент
- Много терпения

## Пошаговая инструкция:

1. Прошейте устройство с джейлбрейком\
   Используйте Legacy iOS Kit, чтобы прошить устройство с встроенным джейлбрейком.

2. Подключитесь по SSH и SFTP\
   Используйте Legacy iOS Kit для подключения по SSH к устройству. Для подключения по SFTP используйте специализированные программы (например, MobaXterm, FileZilla и т.п.).

3. Пройдите начальную настройку до экрана входа в iCloud (или другой ошибки, например "Неизвестное устройство" или требование SIM)

4. Замените файл lockdownd\
   Перейдите по следующему пути на устройстве:
   ```
   /usr/libexec/lockdownd
   ```
   Замените существующий файл на файл lockdownd из этого репозитория, переименуйте его в просто `lockdownd` перед копированием.
   **Важно:** убедитесь, что скачали файл для вашей версии iOS, и **ОБЯЗАТЕЛЬНО сделайте резервную копию исходного файла путем переименования или сохранения на ПК!**
<!--   **Очень важно для iOS 3.x:** процесс замены отличается от iOS 4–6. Путь не `/usr/libexec`, а `/private/var/stash/libexec`. Проверено на iPad 1st gen.
-->
6. Удалять или перемещать Setup.app **НЕ НУЖНО**\
   Процесс настройки пройдёт нормально после замены файла. Не будьте варварами, дайте приложению честно выполнить свою работу.

7. Установите правильные права (очень важно, иначе получите бутлуп!)\
   Выполните следующую команду по SSH:
   ```
   chmod 755 /usr/libexec/lockdownd
   ```
   Или вы можете выставить права с помощью SFTP-программы.

8. Примените изменения\
   Выполните `ldrestart` **ИЛИ** просто перезагрузите устройство.

## Для пользователей CoolBooter

Если вы используете раздел CoolBooter, вы не сможете использовать SFTP на экране активации (OpenSSH не предустановлен, наверное? Так или иначе, у меня не сработало). Вместо этого:

1. Загрузите SSH-ramdisk с помощью Legacy iOS Kit (пользователям A5(X) понадобится checkm8-a5 или kDFUApp).\
2. Примонтируйте раздел CoolBooter вручную:
   ```
   mount_hfs /dev/disk0s1s3 /mnt1
   ```
   (вместо использования `mount.sh`)\
4. Замените файл lockdownd, как описано выше.\
5. Перезагрузитесь и завершите настройку.

## После установки

На вашем устройстве должна быть обойдена активация, при этом сохранена возможность синхронизации с ПК.
